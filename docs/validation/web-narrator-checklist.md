# Browser Narrator check script

Use this script only against a named immutable local browser candidate. It records an operator session; it does not certify accessibility or laboratory competence.

1. Start Narrator through the operating system and open the candidate landing page.
2. Read the landing title, fictional-training boundary, local-data statement, science limit, release-information link, and training-station link.
3. Open the training station. From a fresh load, use Tab and Shift+Tab to confirm focus reaches the level and mode buttons without remaining on the visual canvas.
4. Start one Guided and one Assessment attempt. Confirm that each phase name, status message, forward task control, selected well, and save feedback are announced as plain-language controls or status text.
5. In Level 1, inspect the active-well role table, target/current volume text, reader observations, and debrief tables. In Assessment, confirm explanatory lesson text is not presented before the core model permits it.
6. In Level 2, inspect tube labels versus actual contents, actual plate assignment versus prediction, normal/excitation observation controls, diagnostic evidence cards, uncertainty decisions, and completed debrief claims.
7. Open and close the delete confirmation with keyboard input. Confirm focus enters the dialog, stays between Cancel and Delete, returns to the originating control after Escape, and the dialog identifies only the selected local attempt.
8. Record browser/version, candidate release ID, level/mode, result for each step, any unannounced or misleading control, and whether the browser was online or offline. Do not place learner records in the evidence.

This project has a semantic HTML task panel and keyboard focus checks, but no Narrator or NVDA session is asserted by source tests. A Narrator executable being present on a validation machine only makes this manual check available.
